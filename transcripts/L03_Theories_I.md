## Key Concepts

- **Mercantilism:** Trade surplus = national wealth; export promotion, import restriction
- **Absolute Advantage:** A country has AA in a good if it produces it with fewer inputs than its trading partner
- **Specialisation gains:** Each country specialises in AA good → joint output rises
- **Limitation:** What if one country has AA in everything? (Ricardo's answer next lecture)

## Example (Absolute Advantage)

| | Cloth (hrs/unit) | Wine (hrs/unit) |

| England | 100 | 120 |
| Portugal | 90 | 80 |
